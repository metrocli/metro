Batch / large requests

Use metro shortcuts that already paginate or batch-bound - do not invent fleet loops.

  • metro package list - full tenant package inventory (next_page)
  • metro package customers - contracts on a package
  • metro contract move-plan bulk-preflight|bulk-apply - roster + --delay-ms
  • metro dimensional new-code --all - fleet rate-card append
  • Reviewed usage.batch / usage.groups - pagination in query, not body
  • Ingest ≤100 events/batch; addRates ≤100 rows; retry on 429

Prefer getNetBalance once catalogued instead of N+1 balance pages. See QUICKSTART § Batch and high-volume ingestion.

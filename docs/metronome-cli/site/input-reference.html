Round-trip guarantees

When redaction.normalizedInputSuppressed is false, JSON.parse(normalizedJson) deep-equals normalizedInput.

normalizedHash is a sha256 hash of normalizedInput after sorted-key canonicalization.

When secret-shaped keys or values are detected, normalizedInput, normalizedJson, and normalizedHash are null.
